# Codex 任务书 · 前端 Task 01 —— 工程脚手架 + 设计系统 + 组件画廊

> 用法:把本文件整段贴进 Codex,或放进仓库 `docs/tasks/`。
> 这是前端第一块,完成且设计师确认视觉后,才开始做业务屏幕。

## 你的角色与项目背景

你在为 **Think & Act**(一款帮中文用户完成「今天行动闭环」的 AI 应用)开发 **Android 前端**。
气质关键词:温暖、圆润、像朋友(搭子),不像生产力工具、不像教练。
技术栈:**Kotlin + Jetpack Compose**,单 Activity + Compose Navigation,MVVM(ViewModel + StateFlow),Hilt 注入,本地优先(后续接 Room + Ktor)。

本任务只做三件事:**工程脚手架、设计系统(主题 + token)、一个组件画廊屏**。
**不要**做语音输入、不要做业务流程屏幕、不要接任何网络/真实 API。

## 任务目标

1. 初始化 Android 工程脚手架。
2. 用品牌 token 建一套**自定义 Compose 主题**(不是 Material 默认配色)。
3. 实现一套基础组件(按钮、卡片、输入框、AI 气泡、品牌字标)。
4. 做一个 `ComponentGalleryScreen`,把上述全部组件渲染在一屏,作为活体样式指南,供设计师目测验收。

## 工程脚手架要求

- minSdk 26,targetSdk 取最新稳定,Kotlin 1.9+。
- 依赖先装上但可暂不使用:Compose BOM、Hilt、Navigation-Compose、(Room、Ktor、kotlinx-serialization 先加依赖占位)。
- 包结构按以下骨架建好(本任务只填 `ui/theme`、`ui/common`、`ui/gallery`,其余建空包占位):
```
app/
├── ui/
│   ├── theme/    颜色、字体、形状、主题
│   ├── common/   可复用组件(按钮、卡片、输入、AI 气泡)
│   ├── gallery/  组件画廊屏(本任务交付物)
│   ├── morning/  (空占位)
│   ├── day/      (空占位)
│   ├── evening/  (空占位)
│   ├── history/  (空占位)
│   ├── memory/   (空占位)
│   └── share/    (空占位)
├── domain/       (空占位)
├── data/         (空占位)
└── core/         (空占位)
```
- 单 Activity + Compose Navigation,启动后默认进入 `ComponentGalleryScreen`(临时,后续会改成正式入口)。

## 设计 Token(逐项实现,这 6 项是设计师已确认的硬规格)

| 项 | 值 |
|---|---|
| 背景色 | 温暖米白 `#FBF5F0` |
| 强调色 | 番茄红 `#E54A2E` |
| 英文字体 | Bricolage Grotesque(需作为字体资源打包) |
| 中文字体 | Android 系统 CJK(Noto Sans CJK / Source Han Sans,**不要**用 PingFang,那是 iOS) |
| 时间戳字体 | JetBrains Mono(需打包) |
| 圆角 | 按钮 pill(全圆)· 卡片 16dp · 输入框 12dp · 单选 6dp |
| 阴影 | 温暖偏色调、柔和扩散(不要冷灰硬阴影) |
| 品牌字标 | `think & act`(小写) |
| AI 声音样式 | 比正文浅的颜色 + 圆润舒适的字体 |

### 关于未指定的值(需你提案,设计师确认)
规格里没给正文文字色、次要文字色、卡片表面色、描边色、阴影具体色值。请你从 `#FBF5F0` / `#E54A2E` 这套暖色调里**推导一组协调的中性值**填上,并在代码里用 `// TODO(designer-confirm)` 标注清楚,方便设计师逐个调整。**不要**擅自改动上面 6 项已确认的 token。

### 字体打包提醒
- Bricolage Grotesque、JetBrains Mono 不是系统字体,需放进 `res/font/` 并在 Typography 里注册。
- 如拿不到字体文件,先用最接近的占位字体并明确标注 `// TODO: 替换为正式字体`,不要静默用默认 sans。

## 组件画廊屏要包含

把以下都渲染在一个可滚动的 `ComponentGalleryScreen` 里,每组带小标题:

1. **配色板**:背景、强调色、推导出的中性色,各一块色卡 + 色值标注。
2. **字体样本**:品牌字标 `think & act`、大标题、正文、时间戳(Mono),各一行示例。
3. **按钮**:主要按钮(pill,番茄红)、次要按钮、以及置底大 CTA「looks good」。含按下态。
4. **任务卡片**(16dp 圆角):示例任务一张,含标题、时间(Mono 字体)、★ 重要标记、一行 AI 朋友式注释。再给一张「★ 重要任务」和一张「普通任务」对比。
5. **输入框**(12dp 圆角):底部输入气泡样式,带占位文案「想调整今天的安排?跟我说一声」。
6. **AI 气泡 / AI 声音**:用浅色 + 圆润字体渲染一句 AI 注释,如「上午留了块完整时间给你专注,下午会议后我把跑步排在 19:00。」
7. **单选 / 复选**(6dp 圆角):晚间审核用的三态示意(planned / done / skipped)。

全部用 mock 数据,写死即可,不连任何后端。

## 验收标准(设计师会逐条目测)

1. App 能编译运行,启动直接看到组件画廊,可滚动。
2. 背景是暖米白、强调色是番茄红,**没有任何 Material 默认紫/靛色残留**。
3. 圆角符合规格(按钮全圆、卡片 16、输入 12、单选 6)。
4. 阴影是暖调柔和扩散,不是冷灰硬边。
5. 时间戳确实用 Mono 字体,和正文有明显区分。
6. 整体气质:暖、圆、放松,像朋友——这条由设计师主观判断,你尽量贴近关键词。
7. 所有「推导/占位」的值都用 `// TODO(designer-confirm)` 标了出来。

## 明确不要做的事

- 不要做语音输入(科大讯飞 SDK 是后面的任务)。
- 不要做 morning/day/evening 等业务流程屏幕(等设计系统确认后再做)。
- 不要接网络、不要写 Repository、不要碰真实 API。
- 不要用 Material 3 默认主题配色;必须基于品牌 token 自定义。
- 不要改动 6 项已确认 token;有异议先在回复里说,等设计师确认。
