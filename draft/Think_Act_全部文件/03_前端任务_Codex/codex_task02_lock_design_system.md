# Codex 任务书 · 前端 Task 02 —— 锁定配色 + 照参照重做设计系统

> 用法:把本文件 + `color_direction_compare.html`(视觉参照)一起给 Codex。
> 设计方向已由产品设计师拍板,本任务是**照着做**,不是再探索。

## 决定(已拍板,不要再改)

配色方向锁定为 **陶土 / 暖石墨**(对比图里的"方向 2")。
之前的 3 个方向(番茄红 / 鼠尾草灰 / 冷石墨)**全部作废**,代码里相关的备选主题删掉。

## 视觉参照

随附文件 `color_direction_compare.html`,**右边那个手机屏(陶土)就是目标**。
打开它,你要做的是用 Jetpack Compose 把这个屏的气质、配色、间距、圆角 1:1 还原。HTML 是用来看"长什么样",不是让你抄 CSS——把里面的值翻译成 Compose 的 Color / Shape / Typography。

## 精确色值(逐个填进 Compose 主题)

| 用途 | 色值 |
|---|---|
| 背景(整屏) | `#FBF5F0` 暖米白 |
| 卡片底 | `#FFFFFF` |
| 强调色(★、CTA、时间) | `#B5654A` 陶土 |
| 强调色浅色调(时间药丸底) | `#F0E2DA` |
| 主文字 | `#2E2924` |
| 次要文字(注释) | `#7A7065` |
| 最浅文字(占位符、小标签) | `#A89C8E` |
| AI voice 文字 | `#5E5247` |
| AI voice 气泡底 | `#F4EBE3` |
| 描边 / 分隔线 / 虚线 | `#EADFD4` |

## 形状与阴影

- 卡片圆角:16dp
- 输入框圆角:12dp
- 按钮:pill(完全圆)
- 单选:6dp
- 卡片阴影:暖调、柔和扩散(参考 HTML 里 `0 2px 10px -4px rgba(90,60,30,.16)`,翻译成 Compose elevation + 暖色 shadow)
- AI voice:左侧 3dp 陶土色竖条 + 12dp 圆角 + 浅底(`#F4EBE3`)
- 时间药丸:浅陶土底(`#F0E2DA`)+ 陶土字 + 7dp 圆角

## 字体

- 英文标题 / 字标 / greeting:Bricolage Grotesque(打包进 `res/font/`)
- 中文正文:系统 CJK(Noto Sans / Source Han),**不要 PingFang**
- 时间戳 + 小标签(TODAY / AI VOICE):JetBrains Mono(打包)

## 核心原则(这是上次跑偏的根源,务必守住)

1. **背景永远是米白,绝不用强调色洇满整屏。** 之前那版整个背景粉橙色 = 显廉价,作废。
2. **强调色只点睛**:★、时间药丸、`looks good` 按钮——就这三处。其余全是中性暖色。
3. `looks good` 是全屏**唯一**的大色块(陶土填充 + 白字 + pill)。
4. 留白要够,卡片之间松弛,不要挤。

## 要做的事

1. 把 Compose 主题(Color / Shape / Typography)按上面锁定的值重建,删掉其他备选配色。
2. 把组件画廊重做成对比图右屏的样子:字标、greeting、TODAY 标签、任务卡(★ + 时间 + 注释)、建议卡(虚线、更淡)、AI voice 区、输入框、looks good 按钮。
3. 截图发出来,和 `color_direction_compare.html` 右屏并排对比,确认气质一致。

## 明确不要做的事

- 不要再出配色选项让人选——已经定了陶土。
- 不要把背景洇成彩色。
- 不要改锁定的色值;若你发现某个值在屏幕上实际效果不好,先截图说明、等设计师确认,不要擅自调。
- 不要做业务流程逻辑(这一步只做静态视觉,接口下一步再接)。

## 完成后输出

1. 重建后的 Compose 主题代码 + 组件画廊。
2. 画廊截图。
3. 一句话:有没有哪个色值/间距在真机上和参照图不一致、需要设计师再看的。
