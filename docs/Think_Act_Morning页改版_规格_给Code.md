# Morning 页改版 · 规格(给 Code)

> 视觉基准:`Morning页_输入框加大_设计_v5.html`。本单**落实并取代第六批 B6-02**(输入框加大/中间下移)。
> 原则照旧:只按 demo 重构这一页的布局与顶栏,生成逻辑/语音管道/防抖取消等已修内容**不动**。

## 一、布局(自上而下)

1. **顶栏**:去掉字标(页内不再出现 App 名)。四个**同款圆形图标按钮**,右对齐:
   - 设置(齿轮)/ 历史(柱状图)/ 我的日常(日历):白底、细描边、陶土色线条 SVG;
   - **今天 →**(箭头):陶土实底白图标,突出主导航;
   - 统一尺寸(34dp 圆),**做成通用顶栏组件**——后续执行屏/复盘等页的顶栏将统一用它,别写死在 Morning 里;
   - 图标用矢量(线条风格统一),**不用 emoji**(跨机型长相不一)。
2. **标题区(压扁)**:大标题「**日程规划**」+ 一行副标「把脑子里的今天倒在这里,我帮你收成一条舒服的时间线。」(超长省略,不换行)。
3. **输入框 = 主角**:占满副标以下、语音条以上的**全部空间**(约半屏),多行、内部滚动;底部一条虚线分隔的小字计数(`X 字`,有内容时右侧显示`说多少都放得下`)。占位文案不变。
4. **底部钉死**:语音条「🎤 按住说话」(**样式保持现状不改**;F7-03 的轻点=打字行为照常接)+「生成今天」(无内容灰、有内容陶土实底,可用性判定按第五批 F-11 修过的口径:框内有内容即可)。

## 二、细节
- 键盘弹出:输入框压缩但仍可滚,底部按钮不被键盘盖(ime padding 已有,核对这页)。
- 「生成今天」点击后 loading/取消按已修的那套,不要回退。
- 本页去英文后,**App 名暂不全局改**(终名待定);除本页字标删除外,其他地方名字先不动,等改名派单。
