# Think & Act ｜今天的完整计划页 · 规格(给 Code)

> 视觉对回 `今天完整计划页_设计_v1.html`。
> 定位:**一天当中随时看整天 + 随时改**的活页面。**和复盘不同**:复盘是晚上往回看/总结;这页是看当下/往前、且可编辑。

## 它基本是"拼装",不是重造
复用已有三块:**整天计划视图**(早计划那张)+ **plan-revise 调整**(白天/复盘那套 propose→前后对比→apply)+ **点选微调**(已有)。组合成"全天 + 随时可改"。

## 屏(照 demo)
按时间排的整天时间线:
- **已过去**:完成/跳过,淡显(跳过中性、非红)。
- **进行中**:高亮那条,显「进行中」+ **还剩**(见下逻辑)。
- **「现在 HH:MM」标线**:在进行中那条之后。
- **接下来**:正常显示。
- **建议项(未接受)**:软显示(虚线 + "建议" + **+ 加入**);加入才升级真任务(建议≠任务)。

## 「还剩」文字逻辑(锁定 · 时钟制、无状态、不重置)
- **未开始**(now < 开始):`还剩 = 开始 − now` →「还剩约 X 开始」
- **进行中**(开始 ≤ now < 结束):`还剩 = 结束 − now` →「还剩约 X 结束」
- **已超时**(now ≥ 结束 且未完成):温和「超了约 X · 该收尾了?」,**不显负数**。
- 无固定时间的任务:不显倒计时。
- (执行屏用同一套逻辑;此处仅文字,时间环视觉另议。)

## 随时改(两种)
1. **点任意一条** → 改时间 / 标完成 / 跳过 / 挪走(点选微调,手动)。
2. **底部语音**「按住说一句,改今天」→ **plan-revise → 前后对比确认 → apply**(复用,按住走秒应)。例:"把回消息往后挪半小时""加一件晚上写周报"。

## 入口
执行屏放一个「完整计划 / 列表」图标点进来(首屏也可挂一个)。执行屏=聚焦当前一件;这页=拉远看整天。

## 红线
- **建议≠任务**:软建议不进计数/打勾/推送,+加入才成真任务。
- 语音改一律 **propose→确认→apply**,不静默生效。
- 搭子语气;后端拒绝照实显示 reason、不"没听出"。

## 验收
1. ✅ 整天时间线:过去/进行中/接下来 + 现在标线 + 软建议;进行中显「还剩」按上面逻辑(未开始→到开始、进行中→到结束、超时→温和不负数)。
2. ✅ 点任意条可改;底部语音改走 propose→确认→apply。
3. ✅ 建议项 +加入 才升级;不进计数/推送。
4. ✅ 从执行屏图标可进;与执行屏数据一致。
5. ✅ Android / iOS 一致,真机验,done 老板按效果拍。
