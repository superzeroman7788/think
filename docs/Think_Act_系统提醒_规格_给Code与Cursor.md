# Think & Act ｜★ 任务系统提醒规格(给 Code,BE 极少)

> 范围 = **发朋友这版**。做法:**本地定时通知 + 白名单引导**(轻、零厂商行政)。
> 全厂商通道(极光 + 小米/华为/OPPO/vivo…)做真·全覆盖 = **公开/上架前的 fast-follow**,这版不做。

## 谁该响
- **★ 重要任务** → **系统通知**(本规格)。
- 普通任务 → App 内横幅(已做,不动)。
- **建议项(未接受)→ 永不推送。**

## iOS
- 用 `UNUserNotificationCenter` 给 ★ 任务在 `planned_time` 排**本地通知**。稳、统一。

## Android
- 用 **WorkManager / 精确闹钟**(`AlarmManager` exact;Android 12+ 申请 `SCHEDULE_EXACT_ALARM`)给 ★ 任务在 `planned_time` 排本地通知。
- **计划变就重排**(plan-revise/apply 后重新排该任务的通知);**done/skip/挪走时取消/更新**对应通知。
- **首次引导白名单**:一次性、温和的一屏,引导用户开「自启动 / 允许后台 / 不优化电池」(国内 OEM 会杀后台,不开本地通知可能不响)。**只引导一次,别反复弹、别说教。**

## BE(Cursor,极少)
- ★ 任务的 `planned_time` 数据已在库;本版**不做服务端推送**。Cursor 基本无活,确认数据可读即可。

## 诚实备注(写给自己,别当 bug)
本地定时通知在**激进杀后台的国内 OEM** 上,App 被杀时可能不响——白名单能缓解,够朋友内测。真·全覆盖要走厂商通道聚合(JPush),列为公开前 fast-follow。

## 验收
1. ✅ iOS:★ 任务到点弹**系统通知**;普通任务不弹(走横幅);建议项不弹。
2. ✅ Android(开了白名单):★ 任务到点弹系统通知;计划改 → 通知重排;done/skip → 通知取消。
3. ✅ 首次白名单引导出现一次、温和、不反复。
4. ✅ 真机录屏(各一台 iOS/安卓),done 老板按效果拍。
