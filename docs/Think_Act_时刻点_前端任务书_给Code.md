# 时刻点(钉子)+ 横幅 + 可选日历同步 · 前端任务书(给 Code)

> 视觉基准:`时刻点_钉子设计_v1.html`(两屏:计划页钉子 / 执行屏横幅)。v9 token 不变。
> 配合 Cursor 的 schema(`tasks.kind = block | point`)与抽取规则,**先对账契约再动工**。

## 一、完整计划页 · 钉子渲染

- block 卡片照旧(显示「14:00–18:00」起止 + 进行中显「距结束 X小时XX分」,用全局统一的时长格式化,≥60 分钟显「X小时XX分」)。
- 落在某块时间范围内的 point:渲染在**该块卡片内部下方**的钉子区(虚线分隔):`● 15:00 给老张打电话`;已完成 → 灰点 + 删除线。**块永远是完整一条,不被切开。**
- 不落在任何块内的 point:按时间顺序独立显示为一条细钉子行。
- 点钉子可编辑(改时间/完成/跳过/删除,复用任务编辑)。

## 二、执行屏 · 横幅(块不中断)

- 到 point 时刻:顶部弹**横幅**(样式按 demo):事项 + 时刻 + 「完成 / 待会儿」+ 小字`手头的「XX」不中断,做完这件继续`。
- 当前任务**不切换**,潮水/倒计时照常。
- 「完成」→ point 置 done,横幅收起;「待会儿」→ 10 分钟后再弹一次(**只重弹一次**,再点待会儿就安静回计划页钉子区,不纠缠)。
- ★ 的 point 同时走系统推送(复用现有 ReminderScheduler 精确闹钟通道);普通 point 只走端内横幅。
- 锁屏/不在执行屏时:★ point 系统通知点开 → 直达执行屏并展示该横幅。

## 三、复盘 / 历史

- point 在复盘列表独立一条,三态点选照常;历史"做成/共"计入 point(跳过不计,与现口径一致)。

## 四、可选:★ 任务同步到系统日历(设置开关,默认关)

- 设置页加开关「★ 任务同步到系统日历」:首次打开时申请 `WRITE_CALENDAR`,并用一句话说明用途(`让重要提醒在系统日程里也能看到,App 被清后台也不漏`)。
- 开启后:**仅 ★ 任务(含 ★ point)**在确认计划时写入系统日历(标题 + 起止/时刻 + 提醒);任务改时间 → 更新事件;完成/跳过/删除 → 删除事件。事件备注标记来源(think & act),只动自己创建的事件。
- 关闭开关:删除全部本 App 创建的日历事件。
- 权限被拒:开关回弹并温和说明,不反复索要。

## 五、验收(✅ = 真机端到端 + 证据)

- [ ] 「2点到6点工作,3点提醒我打电话」→ 计划页一块 + 块内一钉;块显示完整起止
- [ ] 15:00 在执行屏:横幅弹出,完成后块的倒计时/潮水从未中断
- [ ] 「待会儿」10 分钟后重弹一次,再待会儿不再弹
- [ ] ★ point 锁屏下系统通知到点响,点开直达执行屏横幅
- [ ] 复盘可独立勾 point;历史计数正确
- [ ] 日历开关:开 → 系统日程里看到 ★ 任务(含提醒);改时间事件跟着改;完成后事件消失;关 → 全部清掉;拒权限不死缠
- 证据:真机录屏(横幅全程 + 系统日历出现/消失)+ build hash
