## 1. 核心隐喻 + 红线（最高优先级）

潮水 = 这条任务**计划时间窗**的流逝。水越高 = 计划时间用得越多。

**验收硬线：绝不做成压力倒计时。** 以下全部禁止，违反即不通过：

- ❌ 任何红色 / 警示色；过点也只是"暖暮色"，不是红。
- ❌ 闪烁、跳动、脉冲式加速、心跳感。
- ❌ 声音、震动。
- ❌ "超时！""快迟到""抓紧"等催促/责备文案。
- ❌ 水位突变、猛涨（必须是平滑过渡，见 §2）。

过点的语气是搭子的"过午饭点啦，先吃还是跳过？"，不是教练的"你超时了"。

## 2. 水位 ↔ 真实时间映射（核心：不是动画自己跑）

demo 里水位靠一个假倒计时驱动；**真机必须用任务的计划时间算**。

```
plannedStart      = 任务 planned_start（与 actual_start 无关）
plannedDuration   = 任务 planned_duration（秒）
plannedEnd        = plannedStart + plannedDuration
now               = 当前时间

elapsed = now - plannedStart
p       = clamp(elapsed / plannedDuration, 0, 1)     // 计划进度 0→1
```

**水位 level（占屏高度比例）按 p 分段：**

| p（计划进度） | level |
| --- | --- |
| 0（刚开始，时间最多） | 0.20 |
| 0.50 | 0.50 |
| 0.833 | 0.78 |
| 1.0（到点） | 0.88 |
| > 1.0（过点） | **0.93 + 暮色态** |

分段公式（与 demo 的 60 分钟曲线完全一致，只是改成按比例、兼容任意时长）：

```
level(p):
  p <= 0.5    →  0.20 + (p / 0.5)              * 0.30   // 0→.20  .5→.50
  p <= 0.833  →  0.50 + ((p-0.5) / 0.333)      * 0.28   // .5→.50 .833→.78
  else        →  0.78 + ((p-0.833) / 0.167)    * 0.10   // .833→.78 1→.88
过点(now >= plannedEnd)：level = 0.93，且进入 .dusk 暮色态
```

**刷新与过渡：**
- 每分钟（或 30s）重算一次 level，水位用 **1.8s, cubic-bezier(.4,0,.25,1)** 平滑补间过到新值——**不准瞬跳**。
- 柔光漂移 / 软浪 / 呼吸（§3）**始终在跑**，与 level 无关，保证任何时刻都有"活着"的微动。

**剩余文案（rem）：**
- `remainingMin = ceil((plannedEnd - now) / 60)`
- `remainingMin > 10`：`还剩约 {remainingMin} 分`（>60 分可显示 `还剩 1 小时+` 类，自行格式化）
- `0 < remainingMin <= 10`：固定显示 **`快到时间了`**，并切到 `.near` 文字色（见 §4）
- 过点：`已过点 · 先吃，还是跳过？`

## 3. 水的外观（精确数值，照抄）

坐标/单位以 demo 的 302×638 画布为参照，CMP 里按屏宽等比换算。

**3.0 设备色差 + 强度旋钮（重要：真机比 demo 浓）**
真机多为 OLED / 广色域（P3），加上 Compose 的 alpha 合成方式与浏览器不同——**同样的暖色半透叠加，在手机上会明显更浓更沉。这是预期，不是数值抄错。**
- 引入一个全局系数 `waterIntensity`，**乘到水所有层的 alpha**（水体渐变 §3.1 + 柔光 §3.3 + 软浪 §3.4）。**demo = 1.0；真机起始 0.65。**
- 只动这一个强度系数；**色相、时长、水位曲线、布局一律不动。**
- Code 在真机上调 `waterIntensity`，调到"看起来像 v5/v6 demo 那种若隐若现的淡"为止，**把最终值报回**，锁进本规格作为基准。
- 起始 0.65 对应的 alpha（可直接照抄起步，= §3.1/3.3/3.4 原值 × 0.65）：
  - 水体（进行中）：`(190,116,86,.22)` / `(202,138,106,.14)` / `(218,166,134,.065)` / transparent
  - 水体（过点 dusk）：`(150,84,60,.26)` / `(174,108,80,.17)` / `(200,142,112,.07)` / transparent
  - 柔光：g1 `.30→.20`、g2 `.24→.16`；★ 重要增量同比例 g1 `.40→.26`、g2 `.32→.21`
  - 软浪整层 opacity `.6→.39`
  - 呼吸（§3.2）区间不变（`.82⟷1.0`）——强度交给本系数，别再叠。

**3.1 水体 — 羽化暖雾（顶边化进透明，无硬线）** *（下列为 demo 原值 = ×1.0；真机按 §3.0 乘 `waterIntensity`）*
垂直渐变（从底→顶）：
- 进行中：`rgba(190,116,86,.34)` 0% → `rgba(202,138,106,.22)` 40% → `rgba(218,166,134,.10)` 74% → `transparent` 100%
- 过点 dusk：`rgba(150,84,60,.40)` 0% → `rgba(174,108,80,.26)` 44% → `rgba(200,142,112,.11)` 80% → `transparent` 100%
- dusk 切换用 **1.4s** 渐变过渡。

**3.2 呼吸（若隐若现）**
整片水透明度：`0.82 ⟷ 1.0`，**9s** ease-in-out，无限循环。

**3.3 柔光（代替波纹，缓缓漂移）** — 两团软光，锚在水面附近
- g1：240×130，左偏 -40、贴水面上方约 -34；色 `rgba(224,172,142,.30)`；漂移 **24s** ease-in-out，幅度 `translate(46, -12)`。
- g2：220×110，右偏 -46、约 -12；色 `rgba(202,134,104,.24)`；漂移 **30s** ease-in-out，幅度 `translate(-40, -8)`。
- 二者各自来回（0→峰值→0）。

**3.4 软浪（仅一道暗示，重度模糊）**
- 贴水面顶边；整层 **opacity .6**、**模糊 ~4px**。
- 浪形 path（viewBox 100×44）：`M0,20 C10,9 16,9 25,20 C34,31 41,31 50,20 C60,9 66,9 75,20 C84,31 91,31 100,20 L100,44 L0,44 Z`
- 填充 `rgba(222,170,140,.6)`；横向平移循环 **24s** 线性（位移一个整周期，无缝）。

**3.5 颗粒（可选）**
轻微噪点纹理，opacity .05、overlay 混合——锦上添花，做不动可省。

## 4. 状态与文案

**4.1 时间胶囊** *（注：最终设计已把时间收进中心时间环 §4.6；独立药丸胶囊 + 扫光被星环取代，**不再单独做**。下面样式仅历史参考。）*
- 等宽字 16，色 clay；白底 .7 + 模糊；pill；clay 描边 .16；柔影。
- **扫光**：一道斜向高光（105°，`transparent 32% → rgba(255,255,255,.6) 50% → transparent 68%`）横扫；周期 **4s**，前半程停在左侧（keyframes：0–55% 在 -130%，78–100% 到 130%）= 扫一下、歇一会儿。

**4.2 剩余文案 rem**
- 常态：cn 13，ink，opacity .66。
- `.near`（≤10 分 / 过点）：色 clay，opacity .9。
- **上浮**：分钟数字变化的那一刻，translateY `0 → -2px → 0`，0.5s——轻轻一跳。

**4.3 状态文案总表**
| 状态 | rem 文案 |
| --- | --- |
| 正常 | 还剩约 X 分 |
| 接近（≤10分） | 快到时间了 |
| 过点 | 已过点 · 先吃，还是跳过？ |
| 完成 | ✓ 已完成（动效见 §4.4） |

**4.4 完成态（点「完成」触发，时序锁死）**
基调 = **松一口气，不是打鸡血**。整段约 1.3s，然后切下一条任务。

| 时刻 | 动作 |
| --- | --- |
| 0s | 触发：取消水位上涨补间 |
| 0–1.0s | **暖涟漪**：一圈环从中心（约屏高 44% 处）荡开一次——`border 2px rgba(224,172,142,.55)`，`scale 1→15`、`opacity .7→0`，1.0s ease-out |
| 0–0.8s | **潮水退去**：水位补间到 **0.08**，过渡临时换成 **0.8s** cubic-bezier(.4,0,.25,1)（比平时快，像呼出一口气） |
| 0–0.5s | **标题区上浮淡出**：center `translateY 0→-12px` + `opacity→0`，0.5s |
| 0–1.3s | **「✓ 已完成」**：居中淡现，disp 700 / 22 / clay，柔白描边；透明度 `0→1(24%)→1(68%)→0`，1.3s |
| 1.3s | **切下一条**：标题/胶囊换成下一任务，水位重置 0.20、清暮色；新内容 `opacity 0→1 + translateY 10→0`（0.55s ease）淡入；之后按 §2 重新上涨 |

- **禁止**：彩带、连击数、+1/积分、勾选音效、震动——搭子不游戏化（§1 红线同样适用）。
- skip 在视觉上同样走"切下一条"的淡出淡入（不必涟漪/✓）；数据落库各走各的（见白天执行腿任务书，skip 清 actual_start）。

**4.5 ★ 重要任务态（叠加在任意水位状态之上）**
基调 = **被温柔护着，不是报警**。重要 ≠ 紧急，绝不变红 / 加急 / 加紧迫。仅三处差异：

- **星标**：标题区上方（"现在"之下、胶囊之上）一枚 `★ 重要`，色 **琥珀 `#D98A3A`**、字号 15、字重 600。
- **标题暖晕**：标题正后方一层羽化暖光，`radial(closest-side, rgba(231,170,108,.34), transparent)`，模糊 ~30，层级在文字之下；进/出 0.6s 渐显。
- **水光增量**：该任务期间两团柔光各浓一档——g1 `rgba(224,172,142,.30) → rgba(230,176,132,.40)`，g2 `rgba(202,134,104,.24) → rgba(212,140,96,.32)`，1s 渐变切换。
- 其余（水位曲线、文案、退潮、完成动效）与普通任务完全一致。

**4.6 中心时间环（星环）— 取代独立时间胶囊（§4.1）**
中心放一枚"星环"补满空旷：**双环 + 8 颗暖星 + 一颗暖光彗星**，环心是当前时间与剩余。视觉源 = `潮水_星环_demo_v9.html`。
布局：`现在`（小字）→ 星环（环心：时间 + 剩余）→ 标题（环下，§4 不变）。容器 200×200（viewBox 100，按屏宽等比缩放）。

*双环（连续，**不要点刻**）*
- 主轨：`circle r=44`，描边 = 竖直线性渐变（顶→底）`#B5654A` 透明度 `.05 → .12(@55%) → .30(@100%)`，线宽 ~1.9，柔光 `drop-shadow(0 1px 5px rgba(181,101,74,.14))`。**底暖顶淡 = 接住下方潮水的光（同一光向）。**
- 外伴轨：`circle r=48`，描边 `rgba(181,101,74,.10)`、线宽 1。**只这两道，不要第三道。**

*8 颗暖星*
- 四角星 clip-path `polygon(50% 0,61% 39%,100% 50%,61% 61%,50% 100%,39% 61%,0 50%,39% 39%)`；填充 `#F6DCAE`，柔光 `drop-shadow(0 0 3px rgba(244,206,150,.8))`。
- 大小 6–12px，散布环带（半径 ≈ 容器 80px ±11、角度大致均分 + 抖动），各带 `-45°~45°` 随机倾斜。
- **位置写死 / 固定种子**——demo 是随机撒的，真机必须固定，否则每次进页面星星跳来跳去显得不稳。
- 闪烁：透明度 `.3⟷1` + 缩放 `.8⟷1.12`，周期 3.2–6.4s、各自随机相位。**慢、淡、不晃眼。**

*暖光彗星（位置 = 时间）*
- 头部 coma：14px 圆，径向渐变 `#FFF7EC 0% → #FCD08C 32% → #EE9C42 64% → 透明 100%`；三层 bloom `0 0 7px 2px rgba(255,231,176,.95), 0 0 16px 5px rgba(238,156,66,.6), 0 0 30px 11px rgba(226,154,82,.34)`；呼吸 scale `1⟷1.16` / 3.4s。
- 尾：conic（from 0°）`透明 0–275° → (232,160,86,.14)@312° → (240,176,104,.44)@344° → (255,226,174,.9)@360°`，裁到主轨环带（带宽约 5px、靠外缘）。头在 360°=正上方。
- **角度 = 时间**：头部角度 = `p × 360°`（顺时针，正上方 0）。**`p` 用 §2 的线性进度 `clamp(elapsed/duration,0,1)`**——注意：**环用线性 p；潮水高度用 `levelFor(p)` 曲线；同一个 `p` 驱动、两种映射。** 每分钟更新，转动补间 1.8s `cubic-bezier(.4,0,.25,1)`。
- **过点**（now ≥ plannedEnd）：`p=1`（头回正上方）+ **整圈轻亮**（`fullglow`：`circle r=44` 描边 `rgba(212,140,96,.45)` + `drop-shadow(0 0 6px rgba(212,140,96,.5))`，1s 渐显）+ 暮色（§3.1）。像走完一圈温温收口——**不变红、不报警**。

*环心文字*
- 时间：等宽 26 / clay，= 任务 `planned_start`。
- 剩余：沿用 §4.2 的 rem（cn 12 / ink .6；`.near` 时 clay .85；分钟变化上浮 2px）。

*CMP 落地注记*
- **双环 + 8 星 + 彗星都用一张 Canvas（commonMain）一次性画**，别拿几十个 View/节点摆（重、双端不一致）。
- 彗星尾**别照搬 CSS 的 conic + 遮罩**（iOS/Compose 对 conic 支持不一）：改用 **`Brush.sweepGradient` 画进环带** + 头部叠径向渐变光点 + 多层柔光。
- 8 颗星坐标 = 固定常量；闪烁/呼吸/转动用 `rememberInfiniteTransition` / `animateFloat`。

## 6. CMP commonMain 实现要点（双端共享）

水效全部画在 **commonMain 的 Compose `Canvas`**（或 `Modifier.drawBehind`），Android / iOS 共用一套。

- **别依赖运行时高斯模糊**（`Modifier.blur` 跨端不一致、低版本缺）。柔光 g1/g2 用 **径向渐变 Brush**（中心实、边缘 transparent）直接画软圆即可，效果等同、全端一致；软浪用半透明 Path 填充，必要时叠一层垂直渐变羽化顶边。
- **水体**：`Brush.verticalGradient(色标同 §3.1)` 填一个高度 = `level * 画布高` 的矩形（底对齐）。
- **level 动画**：`animateFloatAsState(targetLevel, tween(1800, easing = CubicBezierEasing(.4f,0f,.25f,1f)))`。
- **呼吸 / 漂移 / 软浪 / 扫光**：用 `rememberInfiniteTransition` 各开一条（周期见 §3、§4）。
- **rem 上浮**：监听分钟值变化触发一次 0.5s 的 translateY 动画。
- **暮色**：dusk 用第二套色标，切换走 1.4s 的颜色补间。

## 7. 性能

- 当前任务页**可见且为当前任务时**才跑动画；切走 / 锁屏 / 非当前任务 → 暂停所有无限动画，省电。
- level 只每分钟（或 30s）重算；中间靠补间，不要每帧重算时间。
- Canvas 重绘控制在该层，别触发整页重组。

2. ✅ 跨过 planned_end：自动进暮色 + 涨到 .93 + 文案变"已过点 · 先吃，还是跳过？"。

3b. ✅ **真机水色对回 demo**：调 `waterIntensity`（§3.0，起始 0.65）到真机上看着像 v5/v6 那种淡，**最终值报回锁进规格**；只动强度，色相/时长/曲线不动。
