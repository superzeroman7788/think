## F7-03 语音皆有手动替代(原则 + 排查)

现状:实测有些修改**只能靠语音**完成,识别不准/不方便说话时用户没有手动出路。

期望(立成规则):**凡是语音能改的,手动都必须能改。**具体两层——
1. **所有语音条支持打字**:每个"按住跟我说"条,**轻点 = 弹出文字输入**(同一条管道送后端),长按 = 说话。覆盖:执行屏「改今天」、复盘页底部、Morning 输入、记一笔。
2. **点选编辑兜底**:语音能达成的每类变更,都要有纯点选路径——改时间/时长/标题、★、锁定、取消、加一项、加时刻点,统一走完整计划页/提案页的任务编辑弹窗(已有的就核对,缺的补上)。"全部往后推"这类批量操作,手动路径 = 逐项编辑即可,不必做批量按钮。

交付:先给一份**排查清单**(哪些地方现在是语音独占、各自补什么),确认后改;别只修看见的那一处。
