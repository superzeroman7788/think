# Think & Act ｜语音「按住即时反馈 · 秒应」实现规格（给 Code）

> 视觉源 = `按住即时反馈_位置对比_demo.html`（底部模式那版）。
> **一句话**:点下去那一刻 UI **零延迟秒应**,用暖色波形遮住"首字前 ~0.5s"的等待,让体感追上微信/豆包。
> 这是对现有按住态(「在听,说吧」)的**升级**,接到现在那颗 `VoiceMicButton` / `VoiceInputService` 上。

---

## 0. 红线（最高优先）

- **秒应 = 纯本地、零延迟**:`pointerdown` 那一帧就出现,**绝不等**音频采集就绪 / WS 连接 / 首个 partial。反馈层和录音会话**各跑各的**,反馈永远不被连接拖住。这是整件事的意义。
- **克制不浮夸**:暖色、幅度适中、慢而柔;**不变红、不闪烁、不报警**(取消态也不红)。搭子调性。

---

## 1. 触发与时机

- `pointerdown` → **一帧内**同时出现:按钮回弹放大 + 脉冲环 + 波形 + 「在听,说吧」+ 底部柔光罩。全是本地绘制,不依赖任何网络/音频回调。
- 波形**立刻开始动**(先用一个轻微 baseline 起跳),真实 RMS 一进来就接管(见 §7)——所以即便首字还要 ~0.5s,屏幕已经在"应"。
- `pointerup` → 收起反馈(回 baseline),走结尾定稿(沿用已做的端上 VAD 收尾)。

---

## 2. 波形（暖色,微信感）

- **22 根**竖条,宽 4px、间距 4px,容器高 ~64px,圆角 99px(胶囊)。
- 填充:`linear-gradient(180deg, #E29A52, #B5654A)`(琥珀→陶土)。
- 静止基线 `scaleY(0.18)`;`transform-origin:center`(中心向两端长)。
- **幅度映射**(每帧,`sec`=已按住秒数,`amp`=平滑后的 0–1 音量,见 §7):
  - 包络 `c = 1 − |i−(N−1)/2| / ((N−1)/2)`(中间高、两边低)
  - `v = 0.16 + amp*(0.4 + 0.6*c)*(0.6 + 0.6*|sin(sec*5 + i*0.6)|)`
  - `scaleY = min(1, v)`
  - (这套就是 demo 里的值,照抄即可;`i*0.6` 的相位差让条之间错落、像活的声波。)

---

## 3. 位置 + 柔光罩（**底部,不挡内容**）

- 波形锚在**麦克风正上方的底部区**(demo:麦克风 `bottom:40px`、波形组 `bottom:140px`);**不放屏幕中央**(会糊住计划/复盘列表)。
- **底部柔光罩**(只为让波形在花内容上也清晰,**不是全屏压暗**):底部一层向上渐隐的暖罩,高 ~230px,`linear-gradient(0deg, rgba(251,245,240,.96) 30%, rgba(251,245,240,.6) 70%, transparent)`,按住时 0→1(.2s 渐显)。**上面的计划/列表保持可见。**

---

## 4. 麦克风按钮 + 脉冲

- 按钮:72px 圆、`#B5654A`,白麦克风图标,柔影。
- 按下:`scale(1.12)` + 底色转 `#9E5238`,过渡 `.12s cubic-bezier(.34,1.56,.64,1)`(带一点回弹手感)。
- **脉冲环**:按住期间一圈暖环从按钮荡出——`border 2px #B5654A`,`scale .85→2.1`、`opacity .5→0`,1.6s 循环(温和、不急促)。

---

## 5. 文案与状态

- 「**在听,说吧**」(clay `#9E5238`,14、500)在波形下;
- 「**松开结束 · 上滑取消**」(muted `#A7998F`,11)再下一行。
- 都随反馈组一起 0.16s 淡入(`translateY 8→0` + `opacity 0→1`)。

---

## 6. 上滑取消（无 demo,按此做）

- 按住后手指**上滑超过阈值**进入取消区:**波形灰化**(去饱和/降亮)+ 文案转「**松开取消**」。**不变红**(取消是中性动作,灰即可)。
- 在取消区**松手** → **中止**:不送转写、整段丢弃,**零改动**(像 plan-revise 取消的精神)。
- 滑回阈值内松手 → 正常结束、定稿。

---

## 7. 幅度来源（白送的协同）

- 波形的 `amp` **复用 `VoiceInputService` 里 VAD 已经在算的 RMS 能量**——不额外采音。
- 取归一化 RMS(0–1),每帧平滑:`amp += (target − amp) * 0.35`。
- **校准 RMS→amp 映射**:正常说话给"活泼但不顶满"的条高(安静≈短、响≈高但别长期撞 `scaleY(1)`)。
- 真实 RMS 还没来的头 ~100ms:用轻微 baseline 动,别空着。

---

## 8. CMP 落地（commonMain,双端共享）

- **波形用一块 Compose `Canvas` 画 22 根条**(高度 = §2 公式),别拿 22 个 Composable 摆。
- 柔光罩 = 一个 `Brush.verticalGradient` 的 Box(色标见 §3)。
- 脉冲环 / 淡入 / 按钮回弹用 `animateFloatAsState` / `rememberInfiniteTransition`。
- `amp` 从 VoiceInputService 的 RMS 以 Flow/回调喂给 Canvas。

---

## 9. 验收（老板按效果 + 一点数据）

1. ✅ **秒应**:`pointerdown` 到反馈出现 **≤ 1 帧**,且**断网/未连**时照样秒出(证明它不依赖连接)。
2. ✅ 波形**跟真实音量动**(小声短、大声高)。
3. ✅ **底部不挡**:按住时上面的计划/复盘列表仍清晰可见,只有底部柔光罩、非全屏压暗。
4. ✅ **上滑取消**:灰化 + 「松开取消」,取消区松手 = 零改动;正常松手 = 结束定稿。
5. ✅ **克制**:幅度适中、无红、无闪。
6. ✅ Android + iOS 一致(同一套 commonMain);双端录屏,**done 老板按效果拍**。
