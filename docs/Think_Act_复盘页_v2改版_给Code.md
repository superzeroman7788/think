# Think & Act ｜复盘页 v2 改版（给 Code）

> **在现有复盘页上改,不是重写。** 视觉参照 `复盘页_重设计_UI审核_v2.html`。
> 复盘定位:**晚上轻收尾**(不做重反思、不督促)。"提高自律"的引擎是另一条线,以后单独设计——本版先把复盘做对、做轻。

## 1. 删掉「反思」整段
- 移除 ③「反思一下」:**追问问题 + 回答输入框 + "想记住这个"记忆确认卡** 全删。
- 连带:**本页不再有记忆写入入口,`addMemory` 在复盘页不调用**。
- (学习用户节律靠任务行为数据——schema 已采,不靠晚上追问。)

## 2. ②「一句总结」→「今天的提醒」(两块)
把原来那句平铺总结换成一张**两块**的暖卡(文案由 `day-summary` 接口给,搭子语气、每块 1–2 句):
- **上块 · 夸 + 收尾**:暖底,肯定今天**真做成**的事,具体、短。
  **绝不**出现"无深度/无重要完成"这类**数用户没做什么**的句子。
- **下块 · 轻提醒 + 建议**:面向明天的一个温柔小建议,**问句不命令**("明天要不要…?")。
- 视觉:两块同卡、细线分隔,见 demo(praise / advice 两段)。

## 3. 两条语音 → 底部一条
- 删 ① 的"说一句批量改"和 ③ 的"按住说给我听",**合成底部一条统一 press-to-talk**。
- 本页语音只做 **"改今天"**:批量改任务状态,走 `review-parse-voice` → `review-apply`。
- **手动改 = 点行循环** 未做 → 完成 → 跳过(保留)。

## 4. 底部语音条样式
- **去掉填充圆圈**;换**线条麦克风图标** + 文案「按住说一句,改今天」+ 下方一行小例子提示("比如「深度活儿其实做了」")。
- 按住的即时反馈走已出的《语音按住即时反馈_秒应_规格》。

## 5. 红线(不变)
- 语音改:**propose → 确认卡(前后对比)→ apply**,不静默生效。
- 本页**无任何记忆写入**。
- 文案一律搭子语气:不挑刺、不命令、无感叹号。

## 验收
1. ✅ 复盘只剩 ① 审核 + ② 今天的提醒,无反思、无记忆卡。
2. ✅ ② 两块:先夸真做成的、再给明天一个温柔建议;无"数你没做"的句子。
3. ✅ 全页一条底部语音(改今天)+ 点行循环;语音改走 propose→确认→apply。
4. ✅ 底部条无红圈、线条麦克风;按住秒应。
5. ✅ Android / iOS 一致,双端录屏,done 老板按效果拍。
