# 执行屏 · 环心分钟倒计时 + 三态文字 规格(给 Code）

> 视觉基准:`执行屏_v9定稿_三态_v4.html`(在你已做好的 v9 潮水星环执行屏上叠加）
> 一句话:**定稿视觉一个值都不改,只加三样**——① 环心分钟倒计时 ② 三态环心文字 ③ 超时背景不碰(沿用你已定的"潮水回底线"）。

---

## 一、范围

- 这是**增量**,不是重做。v9 定稿的潮水、双星环、彗星+亮点、星尘、呼吸光晕、暖波、grain、★重要态光晕——**全部保持现状,不要重画、不要改值**。
- 任务名已上移到环**上方**(水面以上,潮水盖不到),保持。
- 本次只动**环心文字**和**倒计时取数逻辑**两处。

---

## 二、环心倒计时(分钟,不跳秒)

- **时钟制 · 无状态 · 不重置**:倒计时数值 = 由 `planned_time / planned_end` 与 `now` **当场计算**得出,**不要**引入任何本地计时状态(避免之前 displayStartedAt 重置那类 bug)。
- **只跳分钟**:显示整分钟,跨过整分钟才更新一次,**不跳秒**。
- 颜色暖陶土 `--clay #9E5238`,**不发红、不闪烁**。

---

## 三、三态环心文字

| 状态 | 判定 | 环心(从上到下） | 备注 |
| --- | --- | --- | --- |
| **未开始** | `now < planned_time` | 大「**X 分**」+ 小「**距开始**」 | X = ⌈(planned_time − now)/60⌉。潮水基线、亮点在起点(定稿已有,不动） |
| **进行中** | `planned_time ≤ now < planned_end` | 大「**X 分**」+ 小「**距结束**」 | X = ⌈(planned_end − now)/60⌉;**X ≤ 10 时**小字换「**快到时间了**」。潮水按定稿 `level(p)` 涨、彗星按 p 扫——**这块已实现,不动** |
| **超时** | `now ≥ planned_end` 且未完成 | **三行**:上「**超**」/ 中「**X 分**」/ 下「**该收尾了?**」 | X = ⌈(now − planned_end)/60⌉。背景见第四节 |

**超时「超」字样式(重点）**:柔暖陶土、半透 —— `color: rgba(181,101,74,.55)`,字号约 14px,字距 3px。**不要用纯红/高饱和**,不能有压力感。

「该收尾了?」带问号、温和,**不是命令、不是失败提示**。

**大数字**统一格式:数字(mono)+ 小一号的「分」(中文字、`opacity .66`),如 demo 的 `45<span>分</span>`。

---

## 四、超时背景 —— 不碰

- 超时的**背景/潮水**沿用**你原先和我们定的"潮水回到最底下那条线"**设计。**我这边不强加任何潮水/暮光/环描边效果**,v4 demo 里超时背景就是空着的、只演示文字。
- 即:超时 = (你已有的背景表现) + (本规格新增的环心三行文字)。

---

## 五、无固定时间的任务

- 没有 `planned_time` / `planned_duration` 的任务:**不显示倒计时**,环心不出现「X 分 / 距开始 / 距结束」,更不显负数。按普通任务渲染即可。

---

## 六、红线(沿用,勿破)

- 执行屏**不变红、不闪、不做压力倒计时**。一切走暖色系。
- 超时**不是失败**:文案温和、克制(`该收尾了?`),不催促、不羞辱。
- 倒计时**只跳分钟**,不跳秒。

---

## 七、验收(✅ = 真机跑通 + 证据,不是"组件测过"）

1. 真机分别截图:**未开始 / 进行中 / 超时** 三态,环心文字与本规格一致。
2. 时间跨过 `planned_end` 时,环心**自动**变为超时三行;「超」字色柔和不刺眼。
3. 倒计时**整分钟跳**(盯着看,不应一秒一跳)。
4. 改某任务的时间后,倒计时数值**立即对得上**(验证是时钟制无状态,而非缓存)。
5. 无固定时间的任务:环心**不出现**倒计时。
6. v9 定稿其余视觉(潮水/星环/彗星/星尘/光晕)**无任何回退或走样**。
7. 留 **build hash**;附三态截图。
