# day-summary v2 ·「今天的提醒」两块 — 给 Cursor（**BE 已上线 2026-06-07**）

> 配套 FE：复盘页 v2（`Think_Act_复盘页_v2改版_给Code.md`）。FE 已把 ②「一句总结」改成**两块暖卡**。

## 现状（2026-06-07 实测）
`POST /day-summary` 返回：
```json
{ "provider":"deepseek", "summary":"今天2件事，1件完成1件跳过，深度和重要任务都没搞定，明天得调整节奏。" }
```
- ❌ "深度和重要任务都没搞定" = v2 明令禁止的「数用户没做什么」句式。

## 需 BE 改（v2）
响应**新增两字段**（FE 已能消费，缺则回退）：
```json
{
  "provider":"deepseek",
  "summary":"...(可保留,FE 不再展示)",
  "praise":"三件里做成了两件,健身没被挤掉——能守住这件,挺好的。",
  "advice":"深度工作这两天都被推掉了。明天要不要一早先留一块给它?"
}
```
| 字段 | 口吻要求 |
|---|---|
| `praise` | 只夸**真做成**的事,具体、短(1–2 句);**绝不**出现"无深度/没搞定/没完成"等数缺口的句子 |
| `advice` | 面向明天的**一个**温柔小建议,**问句不命令**("明天要不要…?");无感叹号 |

## FE 行为（已实现）
- `DaySummaryResponse` 已加可选 `praise`/`advice`；有则显示两块,缺 `advice` 隐藏下块。
- BE 未升级前：FE ② 显示「看看今天的提醒」按钮,点了走 `day-summary`；为避免展示旧禁忌口吻,**不再回灌缓存的单句 `ai_summary`**。
- 建议 BE 把 `praise`/`advice` 也 upsert 进 `daily_reflections`(新增两列或复用),供 FE 重进回读、省一次配额。
