> **版本**: v1.0

## 1. 设计目标

- 根据用户 MBTI 类型 + 5 道差异化问答结果，合成唯一命格。  
- 组合空间足够大，确保**同周新用户撞格率低于 5%**。  
- 撞格率公式可验算，参数可调整。

---

## 2. 组合空间定义

命格由以下 6 个维度组合而成：

| 维度 | 数量 | 说明 |
|------|------|------|
| **主属性** | 12 | 对应十二地支意象（子水、丑土、寅木、卯木、辰土、巳火、午火、未土、申金、酉金、戌土、亥水） |
| **副属性** | 12 | 与主属性同集，允许与主属性相同（主副同宫 = 极旺格） |
| **称号** | 64 | 按主副属性组合与等级联合查表，共 64 枚称号 |
| **等级** | 7 | 1~7 星，由答题得分百分位决定 |
| **阴阳** | 2 | 阳 / 阴，由注册时辰决定（00:00–11:59 阳，12:00–23:59 阴） |
| **时运** | 4 | 早(05–10) / 午(11–14) / 晚(15–20) / 夜(21–04)，由注册时段决定 |

### 2.1 组合空间总量

```
N = 主属性 × 副属性 × 称号 × 等级 × 阴阳 × 时运
N = 12 × 12 × 64 × 7 × 2 × 4 = 516 096
```

**有效组合空间约为 51.6 万。**

## 3. 撞格率计算公式

### 3.1 精确公式（生日问题）

设有 n 个同周新用户，组合空间大小为 N，则至少出现一对撞格的概率：

```
P_collision(n, N) = 1 - ∏(i=0 to n-1)(1 - i/N)
```

### 3.2 工程近似公式

当 N ≫ n 时，可用近似：

```
P_collision(n, N) ≈ 1 - exp( - n × (n - 1) / (2 × N) )
```

或进一步简化为：

```
P_collision(n, N) ≈ n × (n - 1) / (2 × N)
```

### 3.3 撞格率验算表

| 同周新用户数 n | 近似撞格率 P | 判定 |
|---------------|-------------|------|
| 50  | 50×49 / (2×516096) ≈ **0.24%** | ✅ 远低于 5% |
| 100 | 100×99 / (2×516096) ≈ **0.96%** | ✅ 低于 5% |
| 200 | 200×199 / (2×516096) ≈ **3.85%** | ✅ 低于 5% |
| 226 | 226×225 / (2×516096) ≈ **4.93%** | ✅ 临界安全 |
| 300 | 300×299 / (2×516096) ≈ **8.69%** | ❌ 超过 5% |

**结论**：在 51.6 万组合空间下，只要同周新用户不超过 **226 人**，撞格率即可控制在 5% 以内。若预期周活新增超过 226 人，可通过提升称号数量或增加时运粒度扩容。

### 3.4 扩容调节公式

如需进一步提升容量，可调参数优先级：

1. **提升称号数**（64 → 128）：空间翻倍，安全阈值提升至约 320 人/周。  
2. **增加时运粒度**（4 → 8）：空间翻倍，安全阈值提升至约 320 人/周。  
3. **增加等级数**（7 → 10）：空间提升 43%，安全阈值提升至约 272 人/周。

## 4. MBTI 映射权重规则

### 4.1 类型到基础属性的映射

16 种 MBTI 类型先映射到 12 主属性的**基础权重向量**（12 维，总和 100）：

| MBTI 类型 | 基础权重倾向（前三名） |
|-----------|---------------------|
| INTJ / INTP | 子水 30、申金 25、亥水 20 |
| ENTJ / ENTP | 午火 30、巳火 25、申金 20 |
| INFJ / INFP | 卯木 30、寅木 25、亥水 20 |
| ENFJ / ENFP | 寅木 30、午火 25、卯木 20 |
| ISTJ / ISFJ | 丑土 30、辰土 25、酉金 20 |
| ESTJ / ESFJ | 戌土 30、未土 25、丑土 20 |
| ISTP / ISFP | 酉金 30、申金 25、子水 20 |
| ESTP / ESFP | 巳火 30、午火 25、戌土 20 |

> 剩余权重平均分配给其余 9 个属性，每项约 1.7–2.8。

### 4.2 差异化 5 道问答设计

每位用户回答 **5 道题**，每道题有 **4 个选项（A/B/C/D）**。题目内容根据用户 MBTI 类型**差异化呈现**，但选项对应的属性权重调整逻辑统一。

#### 4.2.1 出题差异化规则

将 16 型分为 4 大气质组，每组共享题库骨架，但措辞和情境不同：

| 气质组 | MBTI 类型 | 题库风格 |
|--------|----------|---------|
| **NT 分析家** | INTJ, INTP, ENTJ, ENTP | 策略、系统、抽象选择 |
| **NF 外交家** | INFJ, INFP, ENFJ, ENFP | 人际、价值、意义选择 |
| **SJ 守护者** | ISTJ, ISFJ, ESTJ, ESFJ | 秩序、责任、传统选择 |
| **SP 探险家** | ISTP, ISFP, ESTP, ESFP | 行动、体验、当下选择 |

#### 4.2.2 单题权重计算

每道题的 4 个选项对应**属性权重调整向量** Δ（12 维，可正可负，单题四个 Δ 之和为 0）。

用户选择后，累加到基础权重上：

```
最终属性得分 = 基础权重 + Σ(第 i 题 Δ_i)
```

**示例**（INTJ 用户第 1 题）：

| 选项 | 情境描述（NT 风格） | Δ 向量示例（仅列前 3 维） |
|------|-------------------|------------------------|
| A | 优先优化系统效率 | 子水 +8、申金 +4、亥水 +2、其余 -1 |
| B | 先确保规则稳定 | 丑土 +8、辰土 +4、酉金 +2、其余 -1 |
| C | 关注团队感受 | 卯木 +8、寅木 +4、未土 +2、其余 -1 |
| D | 立即行动试错 | 巳火 +8、午火 +4、戌土 +2、其余 -1 |

> **关键约束**：同一选项在不同 MBTI 组的题目中，Δ 向量必须保持一致（即选 A 永远给子水+8 / 申金+4 / 亥水+2），确保算法可复现。

#### 4.2.3 5 道题的分工

| 题号 | 考核维度 | 建议 Δ 总幅度 |
|------|---------|-------------|
| 第 1 题 | 决策风格（思维 vs 情感倾向） | ±10 |
| 第 2 题 | 能量来源（内倾 vs 外倾投射） | ±10 |
| 第 3 题 | 信息获取（直觉 vs 实感偏好） | ±10 |
| 第 4 题 | 处世态度（判断 vs 知觉偏好） | ±10 |
| 第 5 题 | 当前状态（压力 / 松弛 / 专注） | ±15（放大个性波动） |

### 4.3 主属性 / 副属性 / 等级 / 称号的确定

1. **主属性**：12 维得分最高者。  
2. **副属性**：12 维得分次高者（可与主属性同，构成极旺格）。  
3. **等级**：按总分百分位映射到 1–7 星。  
   - 总分 = 基础权重绝对和 + 答题正向调整绝对和（即只加不减的累加）  
   - 映射规则：Top 2% → 7星, 2–10% → 6星, 10–25% → 5星, 25–50% → 4星, 50–75% → 3星, 75–90% → 2星, 90–100% → 1星  
4. **称号**：查 `(主属性, 副属性, 等级)` 联合称号表，64 枚称号均匀覆盖所有组合。  
5. **阴阳 / 时运**：取用户注册时间戳，按时辰规则直接判定，不参与得分竞争。

## 5. 合成流程图

```
用户注册 / 进入命格页
      │
      ▼
获取 MBTI 类型 ────────────────────┐
      │                            │
      ▼                            │
加载基础权重向量（12 维）            │
      │                            │
      ▼                            │
按气质组加载 5 道差异化题目 ◄────────┘
      │
      ▼
用户逐题作答（A/B/C/D）
      │
      ▼
累加 5 个 Δ 向量 → 最终属性得分
      │
      ▼
排序取 Top 2 → 主属性 + 副属性
      │
      ▼
计算总分百分位 → 等级（1~7 星）
      │
      ▼
查称号表 → 称号
      │
      ▼
取注册时间 → 阴阳 + 时运
      │
      ▼
输出完整命格：{主属性, 副属性, 称号, 等级, 阴阳, 时运}
```

## 6. 可验证性检查清单

| # | 检查项 | 验证方法 |
|---|--------|---------|
| 1 | 组合空间 N = 516096 | 直接验算 12×12×64×7×2×4 |
| 2 | 撞格率 < 5% | 代入近似公式 P ≈ n(n-1)/(2N)，n=226 时 P≈4.93% |
| 3 | MBTI 16 型全覆盖 | 检查映射表是否包含全部 16 型 |
| 4 | 差异化题目一致性 | 不同气质组的同一选项 A，Δ 向量必须相同 |
| 5 | 等级百分位单调性 | Top 2% 必为 7 星，100% 必为 1 星，中间不降序 |
| 6 | 扩容可调性 | 调称号数/时运粒度后，N 线性变化，公式仍成立 |
