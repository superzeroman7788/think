# Think & Act ｜历史视图「过去 7 天」规格(给 Code)

> 视觉对回 `历史视图_过去7天_设计_v2.html`。定位:**你这几天的样子,不是成绩单。**

## 入口
顶部一个**图表图标** → 打开「过去 7 天」。

## 数据
按日期读近 7 天的 Task(每天一组)。**无需新 schema / Edge Function** — 直连 REST，见 **[`BE_历史视图_数据读取_给Code.md`](./BE_历史视图_数据读取_给Code.md)**。

## 计数(务必照此,别算错)
- `做成` = 当天 status=**done** 的数（仅 **已接受任务集**：排除 `suggested`、`dropped`）。
- `共`(分母)= **做成 + 真正"未做"的**(status=**planned**；规格里的 todo = 库内 planned)。
- **「跳过」既不进分子也不进分母**(主动放弃 ≠ 漏)。
- **建议项(`status=suggested`)整条排除**,不计入。
- 显示 `做成/共`(如 4/5、2/3、**周六 demo 3/3**)。**不要百分比。**

> Kotlin 对齐：`historyDayStats()` — 同 BE [`task_semantics.ts`](../supabase/functions/_shared/task_semantics.ts)

## 顶部
累计句:**「这 7 天,你做成了 X 件。」**(X = 7 天 done 求和;只增不减、永远正向)。**不显示完成率、不显示连胜。**

## 柱状图
- 每天一根;**高度 ∝ 共(done+未做)**;
- **实色(暖)= 做成,顶部淡斜纹 = 未做**(让"还差几件"轻轻可见);**跳过不画**;
- 今天那根高亮;
- 点某根 → 展开对应那天的卡片。

## 每日卡片
- 折叠:日期 + **一句暖总结** + `做成/共` 徽标;
- 展开:当天任务明细(完成/跳过/未做,**跳过显灰、非红,中性**)+ 当天的**提醒**(直接复用当天 day-summary 的"夸"那半,口吻和复盘一致)。

## 空状态
不满 7 天 / 无数据:暖文案("才刚开始,过几天这里就有你的节奏了"),不报错、不空白。

## 红线
- 无百分比、无连胜、**差日子不标红/不标差**;
- 跳过永不算漏;建议项不计入。

## 验收
1. ✅ `做成/共` 算对:跳过排除、建议项排除(拿 demo 那组数据核对:周六 3/3 而非 3/4)。
2. ✅ 柱子实色+淡纹、今天高亮、点柱展开卡片;无百分比。
3. ✅ 卡片暖总结 + 展开明细(跳过中性)+ 当天提醒。
4. ✅ 空状态暖、差日子不评判。
5. ✅ Android / iOS 一致,真机录屏,done 老板按效果拍。
